# Cadastro de Campanha de Doação
**COMO** usuário do sistema,
**QUERO** cadastrar campanhas de doação,
**PARA** que outras pessoas possam contribuir com a causa.
**Critérios de Aceitação:**

-Deve ser possível informar título, descrição, meta de arrecadação e imagem da campanha.
-O sistema deve validar se todos os campos obrigatórios foram preenchidos.
-O sistema deve exibir mensagem de sucesso após o cadastro.
-A campanha deve aparecer na listagem de campanhas disponíveis.
-O usuário só pode editar ou excluir campanhas que ele criou.
