# DoeMais
O projeto é um sistema web de doações para ONGs, desenvolvido em HTML, CSS e JavaScript. Os usuários poderão criar conta, fazer login, escolher uma ONG, informar o motivo da doação e selecionar para quem desejam doar. O sistema terá interface simples, organizada e responsiva, além de histórico de doações e gerenciamento básico.

## Funcionalidades
- Cadastro de usuários
- Login
- Listagem de ONGs
- Realização de doações
- Histórico de doações
- Gerenciamento básico

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Objetivo
Facilitar doações para instituições sociais de forma simples, organizada e acessível.
