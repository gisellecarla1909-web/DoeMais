Realização de Doações
COMO usuário do sistema,
QUERO realizar doações para campanhas,
PARA que eu possa ajudar causas disponíveis na plataforma.
Critérios de Aceitação:
Deve ser possível selecionar uma campanha e informar o valor da doação.
O sistema deve validar se o valor da doação é maior que zero.
O sistema deve exibir mensagem de sucesso após a doação.
O valor doado deve ser somado ao total arrecadado da campanha.
A doação deve ser registrada com data e informações do usuário.
